# Local generated artifacts

Use this directory for future local captures, imported binaries, large generated
analysis output, logs, and caches. Everything here except this README is ignored
by Git. There are no research artifacts yet.

Keep useful conclusions and evidence references in `docs/research/` or
`docs/validation/`. Record full artifact paths and hashes when needed to
retrieve and identify an input. Do not copy large tool output into startup
instructions.

Git does not preserve ignored files. If an artifact is expensive or impossible
to recreate, retain it deliberately and record its backup or external evidence
location. A retention and backup policy is an open design choice.

This folder is a housekeeping convention, not a selected evidence format,
storage engine, application component, or automatic backup mechanism.
