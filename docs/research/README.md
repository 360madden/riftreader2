# Research notes

No V2 field discovery or live experiment has been performed in this repository.

Use this directory for small, durable findings and references to supporting
evidence. Keep raw captures, imported binaries, generated decompilation, and
large analysis output under the local [artifacts directory](../../artifacts/README.md)
or an explicitly recorded external evidence location.

The [research note template](../templates/research-note.md) provides prompts
for source, build/session identity, observations, failures, and unresolved
interpretations. It is a documentation aid, not an adopted storage schema.

Distinguish evidence status from decision status. Record unsuccessful candidates
when they would prevent repeated work. Preserve enough provenance to find the
source again, including hashes for immutable inputs when available.

When research begins, add a short index of relevant notes here. Summarize
conclusions and reference detailed output rather than copying entire tool logs.
