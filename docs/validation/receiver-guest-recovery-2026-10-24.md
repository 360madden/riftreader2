## Reusable operational lesson

Start the guest receiver **while the cooperative console is free**, before starting the coordinated host, unless authenticated guest control is already available. A never-connected coordinated host may be cleanly stopped under its original no-supervisor shutdown contract; once a supervisor has started, require its actual STOP/release verification before release. Validate large VMware process `startTicks` integers with lossless Python JSON or exact text rather than JavaScript Number serialization.
